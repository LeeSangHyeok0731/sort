# 코드 줄 하이라이트 설계

## 목표
재생 중 현재 연산을 만든 설명용 코드의 줄을 강조하고, 줄별 실행 횟수를 히트맵으로 보여준다.
1차 범위: 버블, 선택, 삽입, 이진 삽입, 퀵, 병합, 힙, 셸, 칵테일, 그놈, 콤, 사이클 (12종).

## 핵심 제약
기존 설명용 코드는 시각화 구현과 동작이 달랐다(삽입 정렬의 밀어내기 vs 교환 등).
→ 12종은 설명용 코드를 실제 기록 방식과 1:1로 맞춘 실행 가능한 JS로 다시 쓴다.

## 데이터
- 연산 로그: `[type, a, b, line]` (OP_STRIDE 3 → 4). line = 0은 "줄 정보 없음".
- `Tracer.cmp/swap/move/mark`에 선택 인자 `line`.
- 설명용 코드 줄 끝 표식 `//@label` → `defineCode(source)`가 표식을 지운 코드, `line(label)`, 줄→표식 맵을 만든다. 없는 표식은 즉시 오류.
- 표식 이름 규칙: `cmp*` 비교, `swap*` 교환, `move*` 이동, `read*` 읽기.
- 공용 헬퍼(insertionSortRange, lomutoPartition, mergeRuns, heapSortRange)는 줄 번호를 선택 인자로 받아, 다른 알고리즘이 쓸 때는 줄 정보 없이 기록된다.

## 재생
Track이 현재 줄과 줄별 실행 횟수를 앞뒤 재생에 맞춰 증감한다. TrackView에 `line`, `lineHits`.

## 화면
- 단일 모드(데스크톱): 막대 오른쪽에 코드 패널. 모바일은 막대 아래.
- 비교 모드: 패널마다 접을 수 있는 코드.
- 현재 줄 강조 + 실행 횟수 히트맵 + 거터에 횟수, 현재 줄 자동 스크롤.
- 미지원 알고리즘은 코드만 표시하고 "줄 하이라이트 준비 중".
- 하단 "구현 코드" 카드는 패널로 옮겨 제거.

## 테스트
- defineCode 파싱·오류.
- 지원 알고리즘 전체: 모든 연산에 줄이 있고, 그 줄의 표식 종류가 연산 종류와 일치. 모든 표식이 한 번 이상 실행됨.
- Track: 앞뒤 재생 시 줄별 횟수 복원.
